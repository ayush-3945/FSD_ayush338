# Day 09: Introduction to React - Components & Props

## Overview
Introduction to React.js fundamentals, covering JSX syntax, reusable components, and props passing from parent to child.

## Features
- **Component Architecture:** Reusable `ChildComponent` profile cards.
- **Props Passing:** Unidirectional data passing from `ParentComponent` to child components.
- **Modern React Setup:** Configured with Vite and React 18.

## Technologies Used
- React 18
- Vite
- Modern CSS
