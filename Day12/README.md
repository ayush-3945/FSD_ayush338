# Day 12: React Todo Application with State

## Overview
A responsive React Todo List application built with Vite, managing state with `useState`.

## Features
- **Task Management:** Create, edit, delete, and mark tasks as completed.
- **Task Analytics:** Displays live counts of pending vs completed tasks.
- **Modern UI:** Clean card layout with action buttons.

## Technologies Used
- React 18 (`useState`)
- Vite
- Modern CSS
