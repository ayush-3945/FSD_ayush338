# Day 11: React Conditional Rendering & Dynamic Lists

## Overview
Demonstration of conditional rendering, array mapping with unique keys, and tab filtering states in React.

## Features
- **Dynamic List Mapping:** Renders task elements using `.map()` with unique `key` props.
- **Conditional Filter Views:** Filter tabs (All, Active, Completed) conditionally display items.
- **Dynamic Styling:** Toggles completion state with conditional strikethrough classes.

## Technologies Used
- React 18
- Vite
- Modern CSS
