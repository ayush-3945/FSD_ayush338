# Day 10: React State Management with useState Hook

## Overview
Understanding React state and reactive UI updates by building an interactive step-counter application using the `useState` hook.

## Features
- **State Handling:** Real-time counter value driven by `useState`.
- **Configurable Step Sizes:** Increment and decrement by custom steps (1, 2, 5, 10).
- **Reset & Boundary Checks:** Zero limit prevention and one-click state reset.

## Technologies Used
- React 18 (useState Hook)
- Vite
- Modern CSS
