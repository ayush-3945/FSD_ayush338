# Day 06: Recommended Jobs Portal

## Overview
An interactive job portal featuring job opportunity cards, modal job details popup, and heart bookmarking.

## Features
- **Job Cards:** Company logos, job title, hourly rate, location, and tags.
- **Modal Popup:** Detailed job description view with modal dismiss functionality.
- **Interactive Bookmarking:** Heart toggle button to save and unsave favorite jobs.

## Technologies Used
- HTML5
- CSS3
- Vanilla JavaScript
