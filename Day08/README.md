# Day 08: Student Management System

## Overview
A complete client-side CRUD web application managing student records using Vanilla JavaScript DOM manipulation.

## Features
- **Create:** Enrolls new student records (Name, Roll No., Course).
- **Read:** Interactive table showing all registered students.
- **Update:** Edit existing student details inline.
- **Delete:** Remove student records dynamically from table.

## Technologies Used
- HTML5
- CSS3
- JavaScript (DOM API, Local State Management)
