# Day 04: Form Validation & DOM Manipulation

## Overview
Interactive student registration form with real-time client-side JavaScript validation and dynamic DOM error feedback.

## Features
- **Field Validation:** Validates full name, email format (Regex), and minimum password length.
- **Dynamic DOM Feedback:** Live inline error messages displayed beneath invalid fields.
- **Success State:** Displays confirmation alert upon valid submission.
- **Form Reset:** Automatically resets inputs on successful registration.

## Technologies Used
- HTML5
- CSS3
- Vanilla JavaScript (DOM Manipulation, Events, Regex)
