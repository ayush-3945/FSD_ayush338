# Day 07: Modular Job Portal with Category Filter & Search

## Overview
An extension of the Job Portal demonstrating modular JavaScript architecture, instant keyword search, and category tag filtering.

## Features
- **Modular Data Architecture:** Separated dataset into external `jobs.js` file.
- **Real-Time Search:** Instant filtering by job title or company as the user types.
- **Category Tag Filtering:** Dynamic filtering by contract type (Full time, Part time, Design).
- **Dynamic Counters:** Automatically updates match count in real time.

## Technologies Used
- HTML5
- CSS3
- Modular JavaScript
