# Day 01: Navigation Bar & Responsive Layout

## Overview
A responsive and clean website navigation bar built using semantic HTML5 and modern CSS3.

## Features
- **Semantic Structure:** Built with HTML5 semantic elements.
- **Active Navigation State:** Distinct visual indicator highlighting the current active tab.
- **Smooth Hover Transitions:** Interactive hover states on all navigation links.
- **Responsive Layout:** Clean centered page layout.

## Technologies Used
- HTML5
- CSS3
