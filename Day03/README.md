# Day 03: Semantic Header & Footer Layout

## Overview
Demonstration of semantic HTML layout containing a responsive Header, Main section, and Footer with integrated social media icons.

## Features
- **Semantic Structure:** Proper `<header>`, `<main>`, and `<footer>` tags.
- **FontAwesome CDN:** Integrated FontAwesome icons (Facebook, YouTube, GitHub, LinkedIn).
- **Flexbox Alignment:** Modern sticky footer layout utilizing CSS Flexbox.

## Technologies Used
- HTML5
- CSS3
- FontAwesome v6
