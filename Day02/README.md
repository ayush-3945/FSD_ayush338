# Day 02: Student Registration Form

## Overview
A comprehensive registration form built with HTML5 form controls and responsive CSS styling.

## Features
- **Form Controls:** Text inputs, email, password, radio buttons (gender), checkboxes (skills), and country dropdown.
- **HTML5 Validation:** Required fields, proper input types, and user prompts.
- **Clean Styling:** Centered card container with soft shadow and organized fieldsets.

## Technologies Used
- HTML5 Forms
- CSS3
