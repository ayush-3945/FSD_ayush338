# Day 05: E-Commerce Store with Fetch API & Shopping Cart

## Overview
A dynamic e-commerce product catalog fetching data asynchronously from an external API, featuring live cart calculations.

## Features
- **Async/Await Fetch:** Loads live products from `https://dummyjson.com/products`.
- **Dynamic Product Grid:** Renders responsive product cards with thumbnail images, titles, and prices.
- **Interactive Shopping Cart:** Real-time badge counter, quantity adjustment (+/-), item removal, and grand total computation.

## Technologies Used
- HTML5
- CSS3
- JavaScript (Fetch API, Promises, Async/Await, Array Methods)
